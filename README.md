# HIO Görselleri

Bu repo **sadece ürün fotoğraflarını** içerir. Fiyat, stok veya katalog verisi bu repoda **bulunmaz** — fiyat verileri özel (private) repoda tutulur.

## Link şeması

```
https://raw.githubusercontent.com/benmertu/hio-media/main/img/<dosya-adi>.png
```

Örnek:

```
https://raw.githubusercontent.com/benmertu/hio-media/main/img/hio-001-cevizli-baklava-1.png
```

## Kullanım

Bu linkler ikas ürün yüklemesinde `imageUrl` alanı olarak kullanılır. Linkler token gerektirmez ve herkese açıktır.

## Yapı

- `img/` — `HIO-xxx` ürün kodlarıyla adlandırılmış ürün fotoğrafları (PNG)
